## 📌 เกี่ยวกับโปรเจกต์ (Project Overview)

**EasyStay** เป็นโปรเจกต์พัฒนาเว็บแอปพลิเคชันสำหรับค้นหาและจองโรงแรม โดยมีเป้าหมายเพื่อให้ผู้ใช้งานสามารถค้นหาที่พัก เลือกห้องพัก ตรวจสอบรายละเอียด และดำเนินการจองได้อย่างสะดวกผ่านหน้าเว็บ

ออกแบบ User Interface ให้มีลำดับการใช้งานที่ชัดเจน ตั้งแต่หน้าแรกที่แสดงข้อมูลโรงแรม ไปจนถึงการเลือกรายละเอียดห้องพักและหน้าสรุปการจองสำเร็จ

นอกจากการพัฒนาแอปพลิเคชันแล้ว ยังนำเครื่องมือด้าน DevOps มาใช้ร่วมกับกระบวนการพัฒนา โดยใช้ Jenkins สำหรับ CI/CD และ Vercel สำหรับการ Deploy เว็บแอปพลิเคชัน

## ✨ จุดเด่นของโปรเจกต์ (Key Highlights)

- **Hotel Discovery:** ออกแบบหน้าค้นหาและแสดงข้อมูลโรงแรม
- **Room Booking:** รองรับการเลือกและจองห้องพัก
- **Room Details:** แสดงรายละเอียดและข้อมูลประกอบการตัดสินใจเลือกห้อง
- **Booking Confirmation:** แสดงผลการจองสำเร็จเพื่อยืนยันรายการจอง
- **CI/CD Pipeline:** ประยุกต์ใช้ Jenkins ในกระบวนการ Build และ Deploy
- **Web Deployment:** นำเว็บแอปพลิเคชันขึ้นใช้งานผ่าน Vercel

## 🚀 ฟีเจอร์ภายในแอปพลิเคชัน (Application Features)

### 01. 🏠 Home Page

หน้าหลักสำหรับแสดงข้อมูลและนำทางไปยังบริการจองโรงแรม

- แสดงข้อมูลโรงแรมและที่พัก
- ออกแบบส่วนแสดงผลให้ผู้ใช้เข้าถึงข้อมูลได้ง่าย
- จัดวางองค์ประกอบเพื่อสนับสนุนการค้นหาและเลือกที่พัก

### 02. 🔎 Hotel Booking

หน้าค้นหาและเลือกโรงแรมที่ต้องการจอง

- แสดงรายการโรงแรม
- แสดงข้อมูลประกอบการเลือกที่พัก
- ออกแบบหน้าจอให้สามารถเปรียบเทียบและเลือกโรงแรมได้สะดวก

### 03. 🛏️ Room Details

หน้ารายละเอียดห้องพัก

- แสดงข้อมูลห้องพักแต่ละประเภท
- แสดงรายละเอียดประกอบการตัดสินใจ
- ช่วยให้ผู้ใช้งานตรวจสอบข้อมูลก่อนเลือกจอง

### 04. 🏨 Room Listing

หน้ารายการห้องพักภายในโรงแรม

- แสดงห้องพักที่มีให้เลือก
- แสดงรายละเอียดและข้อมูลของแต่ละห้อง
- รองรับการเลือกห้องพักตามความต้องการ

### 05. 🎉 Booking Confirmation

หน้าจอแสดงผลการจองสำเร็จ

- แสดงสถานะการจอง
- ออกแบบหน้าจอยืนยันผลลัพธ์หลังดำเนินการจอง
- ช่วยให้ผู้ใช้งานทราบว่ารายการจองเสร็จสมบูรณ์แล้ว

## ⚙️ Development & Deployment

โปรเจกต์นี้มีการนำแนวคิด DevOps และ CI/CD มาประยุกต์ใช้ในกระบวนการพัฒนา เพื่อช่วยจัดการขั้นตอนการ Build และเผยแพร่แอปพลิเคชัน

**Development Workflow**

1. **Development:** พัฒนาเว็บแอปพลิเคชันด้วย Flutter และ Dart
2. **Version Control:** จัดการ Source Code ผ่าน Git
3. **CI/CD:** ใช้ Jenkins ในกระบวนการ Build และจัดการ Pipeline
4. **Deployment:** เผยแพร่เว็บแอปพลิเคชันผ่าน Vercel
